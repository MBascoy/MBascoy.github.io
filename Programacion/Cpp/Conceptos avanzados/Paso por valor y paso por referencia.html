Paso por valor y paso por referencia

Mbascoy.dev / C++ / Paso por valor y paso por referencia
Descripcion

Como pasar valores por referencia y por valor en funciones en C++.

Metodo

A diferencia de C donde pasas la dirección de memoria (para hacer el paso por referencia), en C++ siempre se pasa la variable normal, y despues es en la definición de la función donde se indica si se pasa por valor o por referencia.

Para pasar por referencia se indica con int& variable.

#include <iostream>

void add(int& i, int j){
    i++;
    j++;
}

int main(){
    int i = 50;
    int j = 75;

    add(i, j);

    std::cout << "i:" << i << " j:" << j;
    
    // i: 51
    // j: 75
}
