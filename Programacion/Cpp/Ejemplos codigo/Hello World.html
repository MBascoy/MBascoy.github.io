Como hacer un hola mundo en C++, tanto la manera clásica como el método moderno con módulos.

Hola Mundo clásico
#include <iostream>

int main(){
    std::cout << "Hola mundo!";
}
Hola Mundo con módulos

Para hacerlo con módulos cambios el include por un import, pero a mayores necesitamos hacer la compilación previa de los modulos que usa nuestro programa, en este caso std.

import std;

int main(){
    std::cout << "Hola mundo!";
}

Para compilar el modulo std lo hacemos con:

g++ -std=c++23 -fmodules -fsearch-include-path -c bits/std.cc

Para compilar el código de nuestro programa lo hacemos con:

g++ -std=c++23 -fmodules hola.cpp -o hola_mundo
