Descripcion

Como usar la sentencia for en C++.

Metodo

Podemos usar la sintaxis que se usa en C.

    for(int i=0; i<10; i++){
        std::cout << "i:" << i << "\n";
    }

Range-for-statement

A mayores tambien podemos usar la sintaxis de rangos para simplificar la sintaxis si queremos iterar una serie de elementos:

    int numbers[] = {5,7,9,8,4};

    for(int i : numbers){
        std::cout << "i:" << i << "\n";
    }

    //i:5
    //i:7
    //i:9
    //i:8
    //i:4
