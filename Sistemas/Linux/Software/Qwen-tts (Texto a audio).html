Qwen-tts (Texto a audio)

Mbascoy.dev / Linux / Qwen-tts (Texto a audio)
Descripcion

Como instalar Qwen-tts para generar audio a partir de texto, se puede hacer mediante modelos predefinidos, clonación de voz o diseño de voz.

Github Qwen3-TTS

Instalacion

Para instalar Qwen-tts vamos a hacerlo en un entorno virtual:

python -m venv qwen-tts-env source qwen-tts-env/bin/activate pip install -U pip

Instalamos el paquete de Qwen-tts:

pip install qwen-tts
Generar Voz con modelos predefinidos

Al usar los modelos predefinidos hay que tener en cuenta que no hay ninguno creado con acento español, por lo tanto si se intenta crear un audio en español sonará con acento ingles.

Para crear audio con acento 100% español lo mejor es hacer una clonación con algún audio de referencia que tenga acento español.

import torch
import soundfile as sf

from qwen_tts import Qwen3TTSModel

# Seleccionar dispositivo
device = "cuda:0" if torch.cuda.is_available() else "cpu"

# Cargar modelo
model = Qwen3TTSModel.from_pretrained(
    "Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice",
    device_map=device,
    dtype=torch.bfloat16 if device != "cpu" else torch.float32,
)

# Consultar idiomas y voces disponibles
print("Idiomas:", model.get_supported_languages())
print("Voces:", model.get_supported_speakers())

# Texto que queremos convertir en voz
texto = """
Hola, bienvenido a Qwen tres TTS.
Esta es una prueba de generación de voz
utilizando inteligencia artificial.
"""

# Generar audio
wavs, sample_rate = model.generate_custom_voice(
    text=texto,
    language="English",
    speaker="Vivian",
)

# Guardar audio WAV
sf.write(
    "resultado.wav",
    wavs[0],
    sample_rate
)

print("Audio generado correctamente.")
Generar Voz con diseño de voz

Este metodo tiene el mismo problema que el anterior, aún incluso aunque se le den instrucciones para hacerlo en español no tendrá un acento español como tal

En el siguiente ejemplo se intenta hacer que tenga un acento español, pero aún así no lo consigue, aún así con este metodo si que podemos hacer voces en ingles dando detalles de como queremos que sea

import torch
import soundfile as sf

from qwen_tts import Qwen3TTSModel

model = Qwen3TTSModel.from_pretrained(
    "Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign",
    device_map="cuda:0",
    dtype=torch.bfloat16,
)

texto = """
Hola buenas, esto es una prueba de voz para ver como suena en castellano
"""

instrucciones = """
A native male speaker from Spain, speaking authentic
Peninsular Castilian Spanish (European Spanish).

Use a natural standard Spanish accent from central Spain,
similar to Madrid or Valladolid.

Pronounce the consonants 'z' and soft 'c' with the
characteristic Castilian /θ/ sound.

Avoid Latin American pronunciation.

Warm, mature, natural and professional voice.
Medium-low pitch, clear articulation and relaxed pacing.
Natural Spanish intonation.
"""

wavs, sr = model.generate_voice_design(
    text=texto,
    language="Spanish",
    instruct=instrucciones,
)

sf.write("voz_personalizada.wav", wavs[0], sr)

print("Generación completada.")
Clonación de voz

Este es el mejor metodo que podemos usar si queremos usar voces con acento 100% español.

Con este metodo necesitamos proporcionar un archivo de audio de referencia (he probado .wav y .mp3 y funcionan ambos) y el texto de referencia que se dice en ese audio.

import torch
import soundfile as sf

from qwen_tts import Qwen3TTSModel

model = Qwen3TTSModel.from_pretrained(
    "Qwen/Qwen3-TTS-12Hz-1.7B-Base",
    device_map="cuda:0",
    dtype=torch.bfloat16,
)

# Grabación de referencia
audio_referencia = "Constantino.wav"

# Transcripción de la grabación
texto_referencia = (
    "Estaba haciendo mi turnito de locutor y llamaron dijeron 'oye que te llaman'. Es dificil elegir una pelicula de este señor."
)

# Texto que queremos generar
texto_nuevo = (
    "Hola a todos. Soy Constantino Romero, y me gustaría mandaros un saludo desde el más allá."
)

wavs, sr = model.generate_voice_clone(
    text=texto_nuevo,
    language="Spanish",
    ref_audio=audio_referencia,
    ref_text=texto_referencia,
)

sf.write("voz_clonada.wav", wavs[0], sr)

print("Voz generada correctamente")
