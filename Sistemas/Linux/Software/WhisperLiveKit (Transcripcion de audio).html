WhisperLiveKit (Transcripcion de audio)

Mbascoy.dev / Linux / WhisperLiveKit (Transcripcion de audio)
Descripcion

Como instalar WhisperLiveKit para hacer transcripciones de audio en tiempo real.

Github WhisperLiveKit

Instalacion y ejecucion

Para hacer la instalación de WhisperLiveKit lo vamos a hacer con un entorno virtual en python:

Creamos una nueva carpeta:

mkdir -p ~/whisperlivekit
cd whisperlivekit/

Creamos el entorno virtual:

python3 -m venv whisper-venv

Y lo activamos:

source whisper-venv/bin/activate

Nos aseguramos de que pip esté actualizado:

pip install --upgrade pip

Instalamos WhisperLiveKit:

pip install whisperlivekit faster-whisper

Si tenemos GPU NVIDIA podemos instalar las librerías de CUDA para hacer uso de la GPU en las transcripciones:

pip install nvidia-cublas-cu12 nvidia-cudnn-cu12

Y ahora solo tenemos que ejecutar el servidor de WhisperLiveKit:

wlk --model small --language en --backend faster-whisper

En el parámetro --model podemos elegir varios tamanos: tiny, base, small, medium, large-v2, large-v3, y large-v3-turbo

El small y large-v3-turbo funcionan muy bien, según quieras mas rapidez o mas precisión.

Una vez ejecutado el servidor y descargado el modelo que hayamos seleccionado (puede tardar un rato), accedemos a la interfaz a traves del navegador:

http://127.0.0.1:8000

Una vez aquí solo hay que pulsar el botón de grabar y se transcribirá todo el audio del microfono seleccionado

Opciones extra

Enrutar audio de otras aplicaciones

Para esta aplicación es interesante usar el Enrutamiento de Audio, así podemos transcribir audio que procede de otras aplicaciones.

NOTA: En Google Chrome al enrutarse a si mismo, si quieres usar la interfaz del WhisperLiveKit desde el propio Chrome, NO FUNCIONA, hay alguna caracteristica del navegador que hace que el enrutamiento del audio no funcione, con Firefox por ejemplo si que funciona enrutandose a si mismo.

Detección de participantes

Si a mayores queremos que se identifique a los distintos participantes de una conversación podemos usar la opción --diarization.

Primero tenemos que instalar el paquete:

pip install "whisperlivekit[diarization-sortformer]"

Y despues ejecutamos el servidor con la opción --diarization

wlk --model large-v3-turbo --language en --backend faster-whisper --diarization

De este modo la aplicación marcará cada uno de los participantes de manera individual.

WhisperLive

WhisperLive es una versión alternativa que funciona directamente en la consola, ademas genera automáticamente un archivo de subtitulos (.srt) y exporta tambien el audio grabado (.wav)

Github WhisperLive

Instalación

Para instalarlo lo haremos con un entorno virtual de python.

python -m venv whisper-live-venv source whisper-live-venv/bin/activate pip install --upgrade pip pip install whisper-live

Para hacerlo funcionar necesitamos ejecutar el servidor y el cliente, el código de cada uno se muestra a continuación:

Servidor:

from whisper_live.server import TranscriptionServer

if __name__ == "__main__":
    # Inicializa el servidor de transcripción
    server = TranscriptionServer()

    # Lo ejecuta en el puerto 9090 (puedes cambiarlo si lo deseas)
    print("Iniciando servidor de Whisper-Live en el puerto 9090...")
    server.run(
        host="0.0.0.0",
        port=9090,
        max_connection_time=1800
    )

NOTA: El parámetro max_connection_time define el tiempo máximo que puede estar conectado un cliente, por defecto son 600 segundos, así que hay que tener cuidado porque se puede cortar la transcripción si superamos el tiempo configurado.

Cliente:

from whisper_live.client import TranscriptionClient

client = TranscriptionClient(
    host="127.0.0.1",
    port=9090,
    model="small",
    lang="es",
    save_output_recording=True,
    enable_timestamps=True,
    display_segments=30
)

client()

Ejecutamos el servidor:

python server.py

Y ejecutamos el cliente:

python client.py

Podemos ver las distintas configuraciones en la página de Github del proyecto, pero con el código que hay aquí puesto se guarda el audio automáticamente y el numero de lineas máximas que se muestra en la consola es de 30, todo esto puede modificarse.

Transcribir archivos

Si queremos transcribir archivos de audio lo mejor que podemos usar es el modulo faster-whisper de python.

Instalación

Para instalarlo lo haremos con un entorno virtual de python.

python3 -m venv faster-whisper-env source faster-whisper-env/bin/activate

Actualizamos pip:

pip install --upgrade pip

Instalamos faster-whisper:

pip install faster-whisper

Instalamos las librerías de CUDA (Si tenemos tarjeta Nvidia) para usar la tarjeta gráfica:

pip install nvidia-cublas-cu12 nvidia-cudnn-cu12

Para usar el modulo faster-whisper usaremos el siguiente script:

import sys
from faster_whisper import WhisperModel

parameters_count = len(sys.argv);

if(parameters_count < 2):
    print(f"\nUsage: {sys.argv[0]} <audio_file> [model_size]\n\nModels: \"tiny\", \"base\", \"small\", \"medium\", \"large-v3\" o \"turbo\" \n")
    sys.exit(1)

file_name = sys.argv[1]
model_size = sys.argv[2] if len(sys.argv) > 2 else "base"

# 1. Definir el tamaño del modelo y el dispositivo de cómputo (CPU o GPU)
# Puedes elegir: "tiny", "base", "small", "medium", "large-v3" o "turbo"

# Usa "cuda" si tienes una tarjeta gráfica Nvidia configurada con CUDA, si no, usa "cpu"
model = WhisperModel(model_size, device="cuda", compute_type="float32")

# 2. Ejecutar la transcripción
# Reemplaza "tu_audio.mp3" por la ruta de tu archivo (soporta mp3, wav, m4a, etc.)
segments, info = model.transcribe(file_name)

print(f"Archivo: '{file_name}' \nModelo: '{model_size}'")

# 3. Mostrar información del idioma detectado automáticamente
print(f"Idioma detectado: '{info.language}' con una probabilidad del {info.language_probability:.2f}")

# 4. Imprimir la transcripción con sus marcas de tiempo
print("\nTranscripción:")
for segment in segments:
    print(f"[{segment.start:.2f}s -> {segment.end:.2f}s] {segment.text}")

Para hacer la transcripción de un archivo usamos:

python transcribe.py audio.mp3 turbo

La transcripción se mostrará directamente por consola, si queremos guardarla en un archivo podemos redirigir la salida estandar hacia un archivo:

python transcribe.py audio.mp3 turbo > transcripcion.txt

Troubleshooting

Al ejecutar el script nos podemos encontrar con algunos errores:

Path librerías CUDA

RuntimeError: Library libcublas.so.12 is not found or cannot be loaded

Este error se da al no tener definido el LD_LIBRARY_PATH con las librerías de CUDA, para solucionar el problema editamos el archivo faster-whisper-env/bin/activate y al final añadimos esto:

export LD_LIBRARY_PATH="$VIRTUAL_ENV/lib/python3.13/site-packages/nvidia/cublas/lib:$VIRTUAL_ENV/lib/python3.13/site-packages/nvidia/cudnn/lib:$LD_LIBRARY_PATH"

y volvemos a cargar el entorno vitual con:

source faster-whisper-env/bin/activate

Versión librería ar

Otro error que podemos obtener es el siguiente:

TypeError: open() got an unexpected keyword argument 'metadata_errors'

Este error se da por una versión incorrecta de la librería ar, para arreglarlo instalamos una versión mas antigua que sea compatible:

pip install "av<19"
