Descripcion

Como instalar WhisperLiveKit para hacer transcripciones de audio en tiempo real.

Github WhisperLiveKit

Instalacion y ejecucion

Para hacer la instalación de WhisperLiveKit lo vamos a hacer con un entorno virtual en python:

Creamos una nueva carpeta:

mkdir -p ~/whisperlivekit
cd whisperlivekit/

Creamos el entorno virtual:

python3 -m venv venv

Y lo activamos:

source venv/bin/activate

Nos aseguramos de que pip esté actualizado:

pip install --upgrade pip

Instalamos WhisperLiveKit:

pip install whisperlivekit faster-whisper

Si tenemos GPU NVIDIA podemos instalar las librerías de CUDA para hacer uso de la GPU en las transcripciones:

pip install nvidia-cublas-cu12 nvidia-cudnn-cu12

Y ahora solo tenemos que ejecutar el servidor de WhisperLiveKit:

wlk --model small --language en --backend faster-whisper

En el parámetro --model podemos elegir varios tamanos: tiny, base, small, medium, large-v2, large-v3, y large-v3-turbo

El small y large-v3-turbo funcionan muy bien, según quieras mas rapidez o mas precisión.

Una vez ejecutado el servidor y descargado el modelo que hayamos seleccionado (puede tardar un rato), accedemos a la interfaz a traves del navegador:

http://127.0.0.1:8000

Una vez aquí solo hay que pulsar el botón de grabar y se transcribirá todo el audio del microfono seleccionado

Opciones extra

Enrutar audio de otras aplicaciones

Para esta aplicación es interesante usar el Enrutamiento de Audio, así podemos transcribir audio que procede de otras aplicaciones.

Detección de participantes

Si a mayores queremos que se identifique a los distintos participantes de una conversación podemos usar la opción --diarization.

Primero tenemos que instalar el paquete:

pip install "whisperlivekit[diarization-sortformer]"

Y despues ejecutamos el servidor con la opción --diarization

wlk --model large-v3-turbo --language en --backend faster-whisper --diarization

De este modo la aplicación marcará cada uno de los participantes de manera individual.
