Descripcion

Como crear un microfono virtual y enrutar flujos de sonido entre aplicaciones.

Microfono Virtual

El microfono virtual nos sirve para poder enrutar salidas de audio de otras aplicaciones a una aplicación que requiera un microfono, de modo que el sonido que genera una aplicación entraría como entrada de microfono en otra.

Para crear un microfono virtual podemos hacerlo usando herramientas de PulseAudio o de PipeWire

NOTA: El microfono virtual que creemos desaparecerá al reiniciar el sistema, si queremos que sea permanente tendremos que añadir el comando a un script de inicio.

PulseAudio

Para crear un microfono virtual con PulseAudio usamos el siguiente comando:

pactl load-module module-null-sink sink_name=MicVirtual media.class=Audio/Source/Virtual sink_properties=device.description="Virtual_MIC"

NOTA: Si estamos usando PipeWire y queremos usar este comando necesitamos tener instalado el paquete pipewire-pulseaudio

Si queremos eliminar el microfono virtual que hemos creado primero tendríamos que obtener el numero de ID con el que se ha creado:

pactl list short modules | grep module-null-sink

Y despues usamos el siguiente comando con el ID del dispositivo:

pactl unload-module 124

PipeWire

Para crear un microfono virtual con PipeWire usamos el siguiente comando:

pw-loopback --name=virtual-mic \
--channels=2 \
--channel-map=stereo \
--capture-props='{"node.name":"virtual_mic_sink","media.class":"Audio/Sink","node.description":"Virtual Mic - Input"}' \
--playback-props='{"node.name":"virtual_mic_source","media.class":"Audio/Source","node.description":"Virtual Microphone"}'

Usando este metodo se crearán dos dispositivos que están enlazados, puede ser un poco confuso al verlo en qpwgraph, es mas intuitivo cuando se hace con la herramienta pactl

qpwgraph (Enrutar audios)

Para poder conectar entradas y salidas de distintos programas podemos usar qpwgraph

Podemos instalarlo usando flatpak con:

flatpak install flathub org.rncbc.qpwgraph

Para ejecutarlo:

flatpak run org.rncbc.qpwgraph

Dentro de la aplicación solo tenemos que conectar las salidas y las entradas que queramos enrutar.

Una opción interesante es la de Activated, a veces cuando enrutamos, por ejemplo VLC con el microfono virtual, si pausamos VLC la aplicación desaparecerá de la lista ya que no está reproduciendo sonido, al volver a reanudar la reproducción en VLC volverá a salir la aplicación en el panel, pero las conexiones que hayamos hecho habrán desaparecido, para evitar esto marcamos la opción de Activated y las conexiones se volverán a hacer automáticamente una vez la aplicación vuelva a aparecer en el panel:
